# Project memory

- LCD carousel examples live in creative/previews, referenced by modes[].preview. sync_creative.py generates ModeBitmaps.h as 138x82 RGB565 with aspect-preserving black padding. Pages reads PROGMEM rows and scales through Canvas so clipping and frame tracking stay intact. Missing preview fields retain the tint placeholder; a configured missing file fails the creative build.

- A generated prompt truncated at a space caused h11 Illegal header value after successful image generation. HTTP metadata previews must be printable ASCII, collapse controls/whitespace, and strip after truncation. Full prompts remain unchanged in generation and saved JSON. Test response serialization through h11, not just Response construction.

- `/v1/process` maps all pipeline exceptions to HTTP 502, so that access-log status alone does not identify an upstream outage. The endpoint now logs the traceback through uvicorn.error, and the USB bridge preserves the JSON error body in its terminal error. Diagnose the actual exception before changing timeouts or retrying image requests.

- Grok edit prompts lead with concrete changes; image-provider constraints follow the edit. Do not force every liberal style into illustration, since SURPRISE includes photographic treatments. Its treatment, palette, and focus are selected in Pipeline, exclude the previous choices within that instance, and are saved in context metadata.
- The user rejected the stronger mood pass: repeated mood emphasis and permission for atmospheric details encouraged scenery. All styles now lead with concrete rendering techniques; mood is at most one secondary lighting sentence. Astronomy stays metadata only, with no moon-specific effect selection. Both prompt paths consume only selected artifacts, never raw summary or mood_watermark. Preserve interiors and existing skies/ceilings. Open-Meteo requests wind_speed_unit=ms to match wind_ms thresholds.

- Run project commands through `nix develop`. Verify with builds and offline tests; leave flashing and LCD checks to the user.
- JPEG corruption and persistent `plating...` were traced to a linker collision, not the USB cable. The ESP camera decoder and TJpg_Decoder export `jd_prepare` and `jd_decomp` with incompatible structures and RGB output formats. Keep display decoding entirely on TJpg_Decoder. Calling `jpg2rgb565` pulls the conflicting camera decoder into the firmware.
- Adafruit RGB bitmap APIs accept native RGB565. TJpg byte swapping must be disabled for both the RAM canvas and direct LCD drawing.
- The saved SD samples matched server JPEGs byte for byte. `HOST DREAM`, `USB cook ok`, and `UI review` indicate receipt succeeded; they do not prove decoding or SD writes succeeded.
- USB cooks carry request IDs and CRC32. DREAM payloads follow a receiver-ready handshake, with a final ACK after integrity checks. Never replay a partial transfer after reconnecting. Update firmware and bridge together.
- Preserve SD shots across reboot by skipping existing pair filenames. Storage includes persisted photos plus RAM fallback for failed saves. Review timing begins when a decoded image or error is presented.
- Regression command: `nix develop -c pio run`, then `nix develop -c python -m unittest discover -s tests -p 'test_*.py' -v`. Decoder tests inspect the firmware map, so build first.
- LCD text uses Adafruit byte-oriented fonts, not UTF-8. Keep displayed strings printable ASCII. The creative generator validates mode and brand text; backend prompts may still contain Unicode.
- Cooking icons must use connected strokes and stay inside the existing 40x40 tiles. Keep their motion readable at the current USB-wait redraw cadence.
- Creative prompt-only edits need a server restart. Mode, theme, font, and logo edits need `nix develop -c ./scripts/sync_creative.sh` followed by rebuilding and flashing firmware.
- The user reports the existing `orientLandscapeFrame` landscape rotation/crop is almost correct and explicitly resumed camera changes. Their final correction means horizontal mirroring, not a 180-degree rotation. `Defaults::kCameraMirrorHorizontal = true` mirrors the corrected landscape pixels before preview/JPEG encoding. Set it to `false` and reflash to undo only the mirror. Native asymmetric pixel tests cover both settings at both capture sizes; the new mirror still needs the user's hardware check.
- Fit carousel titles through `Brand::drawTitleIn` using the existing custom font. `Text::drawIn` bounds classic text with ASCII ellipsis. Keep card layering sorted by animated depth and initialize the slide offset before drawing a changed selection.
- LCD animation bandwidth was limited by full 76,800-pixel flushes at 10 MHz. Canvas compares final pixels with the previous frame in PSRAM, splits changed runs across unchanged gaps, and falls back to full flushes if history allocation fails. All normal LCD rendering must stay inside Canvas frames for that history to remain accurate.
- Cooking wait animations are pumped every 100 ms before the DREAM header. Never pump the UI while receiving JPEG bytes or the trailer; the checked USB handshake keeps binary reception exclusive.
